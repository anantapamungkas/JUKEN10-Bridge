# JUKEN10 Bridge

Repositori ini berisi berkas desain elektronik JUKEN10 Bridge yang dibuat menggunakan KiCad. Desain skematik dibagi ke beberapa bagian agar rangkaian lebih mudah ditinjau dan dikembangkan.

## Isi repositori

- `JUKEN10 Bridge.kicad_pro` — berkas proyek KiCad.
- `JUKEN10 Bridge.kicad_sch` — skematik utama proyek.
- `JUKEN10 Bridge.kicad_pcb` — berkas tata letak PCB.
- `Section A - Power.kicad_sch` — bagian rangkaian catu daya.
- `Section B - MCU_sch.kicad_sch` — bagian rangkaian mikrokontroler.
- `Section C - Throtle.kicad_sch` — bagian rangkaian throttle.
- `Section D - Input.kicad_sch` — bagian rangkaian input.
- `Section E - Analog Input.kicad_sch` — bagian rangkaian input analog.
- `project_architecture.kicad_sch` — skematik arsitektur proyek.

## Membuka proyek

1. Pasang KiCad 10 atau versi yang lebih baru.
2. Buka `JUKEN10 Bridge.kicad_pro` melalui KiCad.
3. Gunakan **Schematic Editor** untuk meninjau skematik dan **PCB Editor** untuk melihat tata letak papan.

## Catatan

Berkas kunci sementara, preferensi lokal KiCad, cache footprint, dan folder cadangan otomatis tidak disertakan dalam kontrol versi. Lihat [`.gitignore`](./.gitignore).
